# C# Deep Dive — обучалка-игра

Интерактивный сайт для глубокого изучения C# в формате «миры и уровни».
Чистая статика (HTML/CSS/JS), без сборки и сервера — готово к GitHub Pages.

## Что внутри
Миры → уровни. Каждый уровень: теория простыми словами → живой пример кода
(с подсветкой) → ссылки на доки/книги → задание с проверкой. Прогресс и XP
сохраняются в браузере (localStorage).

Три языка: русский, английский и армянский — переключатель `RU / EN / ՀԱՅ` в
бургер-меню. Выбор запоминается, а прогресс общий (у уроков одни и те же id во
всех версиях). В армянской версии технические термины оставлены по-английски.

Темы:
- **ООП: объекты и связи** — классы, инкапсуляция, is-a/has-a/uses-a, наследование и `base`,
  ассоциация/агрегация/композиция, обобщение, абстрактные классы, полиморфизм, интерфейсы,
  проблема ромба, типичные ошибки в связях, extension methods
- **Generics** — дженерики, обобщённые методы, ограничения
- **Variance** — ковариантность (`out`), контравариантность (`in`), инвариантность
- **Enumerables** — `IEnumerable`/`IEnumerator`, `yield`, ленивое выполнение, LINQ
- **FileStream I/O** — потоки, чтение/запись, `using`/`Dispose`, async
- **Делегаты и события** — делегаты, `Func`/`Action`, лямбды, мультикаст, `event`, паттерн **EventBus**
- **Design Patterns** — все 13 паттернов из лекции (Creational / Structural / Behavioral)

## Файлы
- `index.html` — точка входа
- `styles.css` — оформление
- `data.js` — весь учебный контент (RU)
- `data.en.js` — тот же контент на английском (те же id миров и уроков)
- `data.hy.js` — тот же контент на армянском
- `app.js` — логика (роутинг, прогресс, квизы, подсветка кода, словарь интерфейса)
